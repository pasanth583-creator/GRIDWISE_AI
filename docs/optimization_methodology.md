## 1. Two-Stage Stochastic Programming Overview

In campus microgrid operation, decision-makers face a temporal asymmetry: **day-ahead electricity purchases must be locked in 12 to 24 hours in advance**, whereas rooftop solar PV generation and building cooling/lighting loads depend on realized next-day weather.

Deterministic approaches substitute expected mean forecasts into the optimization problem. While mathematically simple, deterministic policies ignore the non-linear asymmetric recourse costs incurred when real-time demand surges or cloud cover suddenly collapses solar output.

Stochastic programming models uncertainty explicitly as a probability distribution over discrete scenarios $\Omega = \{\omega_1, \dots, \omega_N\}$, optimizing first-stage day-ahead contracts $x_t$ such that the expected recourse cost across all realizations is minimized.

---

## 2. Stochastic Metrics: VSS and EVPI

To rigorously measure the value generated by the stochastic optimization engine, we evaluate three standard mathematical benchmarks:

```
  Wait-and-See (WS)        Recourse Problem (RP)      Expected Value Policy (EEV)
 ┌──────────────────┐      ┌──────────────────┐      ┌─────────────────────────┐
 │ Perfect Foresight│      │ Stochastic Model │      │ Deterministic Policy    │
 │ Optimized per-   │  ≤   │ Committed Stage 1│  ≤   │ Evaluated across all    │
 │ scenario         │      │ + Optimal Recourse│     │ uncertainty scenarios   │
 └──────────────────┘      └──────────────────┘      └─────────────────────────┘
         ▲                          │                             ▲
         └────────── EVPI ──────────┴──────────── VSS ────────────┘
              (RP - WS >= 0)                  (EEV - RP >= 0)
```

### 2.1 The Value of the Stochastic Solution (VSS)

The Value of the Stochastic Solution measures the explicit cost reduction achieved by committing to the stochastic first-stage plan $x_{stoch}^*$ versus committing to the naive deterministic plan $x_{det}^*$:

$$\text{VSS} = \text{Cost}(\text{EEV}) - \text{Cost}(\text{RP})$$

#### Step-by-Step VSS Calculation:
1. **Solve Expected Value Problem (EV):**
   Replace uncertain parameters with their probability-weighted expectations $\bar{D}_t = \sum_{\omega} \pi_\omega D(\omega, t)$ and $\bar{P}_{pv, t} = \sum_{\omega} \pi_\omega P_{pv}(\omega, t)$. Solve a single-scenario LP to find $x_{det}^*$.
2. **Evaluate Deterministic Policy under Uncertainty (EEV):**
   Fix $x_t = x_{det}^*(t)$ as an immutable equality constraint and solve the second-stage recourse problem across all 500 stochastic scenarios. The resulting probability-weighted expected cost is $\text{EEV}$.
   *(Note: Naively using the EV objective is invalid because it assumes expected conditions will occur with certainty).*
3. **Compare with Recourse Problem (RP):**
   Solve the full two-stage stochastic model to find optimal expected cost $\text{RP}$.
4. **VSS Result:**
   $$\text{VSS} = \text{₹}70,681.64 - \text{₹}69,540.75 = \mathbf{\text{₹}1,140.89 / \text{day}} \quad (1.61\% \text{ reduction})$$

---

### 2.2 Expected Value of Perfect Information (EVPI)

The Expected Value of Perfect Information measures the maximum monetary amount the campus microgrid would pay for an omniscient weather forecast before committing day-ahead purchases:

$$\text{EVPI} = \text{Cost}(\text{RP}) - \text{Cost}(\text{WS})$$

#### Step-by-Step EVPI Calculation:
1. **Solve Wait-and-See Model (WS):**
   For each scenario $\omega \in \Omega$ independently, assume perfect foresight. Solve 500 separate deterministic optimization problems where $x_{\omega, t}$ can tailor itself perfectly to scenario $\omega$.
2. **Compute Expected WS Cost:**
   $$\text{Cost}(\text{WS}) = \sum_{\omega \in \Omega} \pi_\omega \cdot \text{Cost}^*(\omega)$$
3. **EVPI Result:**
   $$\text{EVPI} = \text{₹}69,540.75 - \text{₹}68,070.84 = \mathbf{\text{₹}1,469.91 / \text{day}} \quad (2.11\% \text{ of RP})$$

---

### 2.3 Verification of the Fundamental Theorem of Stochastic Programming

A foundational theorem in operations research establishes that for any convex minimization problem:

$$\text{Cost}(\text{WS}) \le \text{Cost}(\text{RP}) \le \text{Cost}(\text{EEV})$$

In our 500-scenario execution:
$$\text{₹}68,070.84 \;\le\; \text{₹}69,540.75 \;\le\; \text{₹}70,681.64$$

Both inequalities hold strictly, mathematically validating that:
* **$\text{EVPI} = \text{₹}1,469.91 \ge 0$** (Information has non-negative economic value).
* **$\text{VSS} = \text{₹}1,140.89 \ge 0$** (Stochastic optimization strictly outperforms deterministic planning).

## 3. Computational Architecture & Sparse Matrices

With $N = 500$ scenarios, the two-stage model contains:
* **Variables:** $24 + 6 \times 24 \times 500 + 1 + 500 = \mathbf{72,525\text{ variables}}$
* **Equality Constraints:** $2 \times 24 \times 500 = \mathbf{24,000\text{ rows}}$
* **Inequality Constraints:** $24 \times 500 + 500 + 500 = \mathbf{13,000\text{ rows}}$

A dense constraint matrix would require $(24,000 + 13,000) \times 72,525 \approx 2.68 \times 10^9$ double-precision floats ($\approx 21.4\text{ GB}$ of RAM), leading to severe memory exhaustion.

### High-Performance Sparse Assembly
Using `scipy.sparse.csr_matrix` and coordinate list (COO) builders:
* Density of the constraint matrix is only **$0.012\%$** (over $99.98\%$ zeros).
* Peak RAM footprint is reduced from $21.4\text{ GB}$ to under **$18\text{ MB}$**.
* The **SciPy HiGHS interior-point / dual-simplex solver** solves all 500 scenarios in **$2.53\text{ seconds}$** with equality residuals below $1.14 \times 10^{-13}$.
