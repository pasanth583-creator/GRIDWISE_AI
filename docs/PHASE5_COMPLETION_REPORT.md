### 3.2 Value-at-Risk (VaR) and Conditional Value-at-Risk (CVaR)
Using the Rockafellar-Uryasev convex representation:
$$\text{VaR}_\alpha = \min \{ \gamma : \mathbb{P}(C_s \le \gamma) \ge \alpha \}$$
$$\text{CVaR}_\alpha = \min_{\gamma} \left\{ \gamma + \frac{1}{1 - \alpha} \sum_{s=1}^S p_s [C_s - \gamma]^+ \right\}$$

| Confidence Level ($\alpha$) | Value-at-Risk ($\text{VaR}_\alpha$) | Conditional Value-at-Risk ($\text{CVaR}_\alpha$) | Tail Spread ($\text{CVaR} - \text{VaR}$) |
|---|---|---|---|

| **$\alpha = 95\%$** | ₹101,273.67 | ₹104,400.74 | ₹3,127.07 |
| **$\alpha = 99\%$** | ₹109,720.50 | ₹112,410.88 | ₹2,690.38 |

## 10. Scientific Rigor, Assumptions & Limitations

1. **Synthetic Data Labeling:** In compliance with ethical data governance, all analytics displays, PDF reports, and CSV streams carry the mandatory tag: `"SYNTHETIC SIMULATION DATA – NOT LIVE METER DATA"`.
2. **First-Stage vs Second-Stage Separation:** Day-ahead grid procurement decisions are made prior to observing weather uncertainty and are common across all 500 scenarios. Real-time balancing and battery adjustments occur in stage two with complete scenario realization.
3. **Linearized Degradation Model:** Battery degradation is modeled at ₹$0.20/\text{kWh}$ throughput based on typical LiFePO4 cell aging curves, representing cycle wear without non-linear calendar aging terms.
4. **Tariff Stationarity:** Time-of-use tariffs follow a three-tier day-ahead schedule. Real-time imbalance settlement assumes hourly balancing price parity.
5. **Phase Boundary:** Phase 5 is fully accomplished. No Phase 6 tasks or extraneous features were initiated.
